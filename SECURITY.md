# Security Policy

## Supported versions

Only the latest release of this project is supported with security updates.

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |

## Reporting a vulnerability

Please **do not** open a public issue for security vulnerabilities.

Instead, report them privately by emailing the maintainers or via GitHub's
[private vulnerability reporting](https://docs.github.com/en/code-security/security-advisories/guidance-on-reporting-and-writing-information-about-vulnerabilities/privately-reporting-a-security-vulnerability)
feature.

When reporting, please include:

- A description of the vulnerability and its potential impact.
- Steps to reproduce the issue.
- Any relevant logs or proof-of-concept code.

You should receive an acknowledgement within a few days. We will keep you
informed as the issue is triaged and resolved.
